# DeepSeek AI 翻译助手（Chrome 扩展）

用 **DeepSeek** 一键**全文翻译**当前网页，也支持翻译选中的文字、填入输入框。

## 功能

- **全文翻译**：抓取页面可见正文 → 按语义分批发送给 DeepSeek → 直接在原位置替换为译文，保留原有排版、链接与样式
- **沉浸式双语对照**：译文以独立段落显示在原文下方（虚线分隔），按钮、链接等内联元素则紧跟其后，效果类似 Immersive Translate
- **三种显示模式**：双语对照（默认）/ 仅译文 / 还原原文，页面右上角面板随时切换
- **多种触发方式**：右键菜单、快捷键、扩展弹窗按钮；快捷键失效时还有页面级兜底监听
- 12 种目标语言：简中、繁中、英、日、韩、法、德、俄、西、葡、意、阿
- 渐进式翻译：边翻边替换，右上角面板显示进度，可随时停止
- 跳过代码块 / 跳过隐藏元素，技术文档不易被破坏
- **单条翻译**：弹窗中「源语言 → 目标语言」自由选择（源语言支持自动检测）
- 选中文字即时翻译并替换为英文（原「中译英」功能保留）

## 安装

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本文件夹
3. 点击扩展图标 → ⚙ 设置 → 填入 DeepSeek API Key（[点此获取](https://platform.deepseek.com/api_keys)）→ 保存
4. 建议顺手在设置页选择「目标语言」

> Edge、Brave 等 Chromium 内核浏览器同样可用。

## 使用方式

| 操作 | 说明 |
| --- | --- |
| 右键页面空白处 → **DeepSeek 全文翻译此页** | 最常用 |
| 快捷键 `Alt + Shift + T` | 全文翻译当前页（可在 `chrome://extensions/shortcuts` 修改） |
| 快捷键 `Alt + Shift + R` | 还原为原文 |
| 快捷键 `Alt + Shift + S` | 翻译选中的文字（替换为英文） |
| 扩展图标 → 选目标语言 →「翻译此页」 | 不用快捷键也能用 |
| 选中文字 → 右键「用 AI 翻译为英文」 | 局部翻译并可撤销 |

翻译过程中右上角会显示进度面板：

- **译文 / 双语 / 原文**：三种显示模式一键切换
- **停止**：中断剩余批次，已翻译部分保留
- **×**：关闭面板（不影响当前译文；用「原文」按钮或 `Alt+Shift+R` 恢复）

### 关于 Ctrl + T 与快捷键切换

Chrome / Edge 把 `Ctrl + T`（新建标签页）设为**浏览器保留快捷键**，`chrome.commands` 无法注册它，网页脚本也拦截不到。因此默认使用 `Alt + Shift + T`。

**快捷键无效或想换键位**：

1. 打开 `chrome://extensions/shortcuts`（设置页里也有入口链接），找到「DeepSeek AI 翻译助手」
2. 点击对应动作右侧的编辑框，按下想要的组合键即可
3. 若编辑框显示灰色 / 提示冲突，说明该组合已被其他扩展或浏览器占用，换一个组合即可

扩展还内置了**页面级快捷键兜底**：即使 Chrome 的 commands 机制没触发（焦点在地址栏、快捷键被占用等），只要页面处于焦点状态，`Alt+Shift+T / S / R` 依然有效（由 background 统一节流，不会重复翻译）。

## 设置项

| 项 | 说明 |
| --- | --- |
| API Key | 仅保存在本机 `chrome.storage.sync`，只与 api.deepseek.com 通信 |
| 模型 | `deepseek-chat`（推荐，快）/ `deepseek-reasoner`（推理强，慢） |
| 目标语言 | 全文翻译的落地语言 |
| 页面默认显示 | 双语对照（沉浸式，默认）/ 只显示译文 |
| 每批字符数 | 默认 1200。偏小批次更稳，偏大更省请求 |
| 并发请求数 | 默认 3，最大 6。越大越快，但更容易触发限流 |
| 单页最多段落数 | 默认 1200，防止超长页面耗尽额度 |
| 跳过代码块 | 默认开启，`code` / `pre` 不翻译 |
| 创造性 temperature | 翻译建议 0.1 ~ 0.4，默认 0.3 |
| 术语表 | 每行 `源 -> 目标`，保证术语一致 |
| 自定义提示词 | 填写后将覆盖内置的单条翻译提示词 |

> 弹窗里的「源语言 / 目标语言」是单条翻译专用的（默认 自动检测 → 英语），与全文翻译的目标语言相互独立；选中文字的右键翻译固定译为英文。

## 文件结构

```
manifest.json    扩展清单（MV3）
background.js    DeepSeek 调用（单条 / 批量）、右键菜单、快捷键
content.js       全文抓取、分批翻译、DOM 替换、翻译面板；选中替换
content.css      翻译面板与双语标记样式
langs.js         目标语言列表（popup / options / background 共用）
popup.*          弹窗：翻译此页、目标语言、单条翻译
options.*        设置页
icons/           图标
```

## 常见问题

- **HTTP 401**：API Key 错误或失效。
- **HTTP 402**：DeepSeek 账户余额不足。
- **HTTP 429**：请求过快，降低「并发请求数」或稍后重试（插件会自动重试两次）。
- **译文数量对不上 / 部分段落没翻**：调小「每批字符数」。
- **某些页面没反应**：`chrome://` 页面、PDF 查看器、应用商店页不允许注入脚本。
- **块状变形**：翻译只改文本节点，不改动结构；若页面本身结构复杂可切「双语」确认对应关系。
