# 中译英 AI 助手（Chrome 扩展）

输入中文，调用 **DeepSeek** 生成地道英文；支持一键填入网页输入框、右键选中直接替换。

## 功能

- 弹窗输入中文 → 英文，支持 5 种风格（自然日常 / 商务正式 / 学术严谨 / 简短口语 / 礼貌邮件）
- 「填入网页输入框」：把译文插入当前页面正在编辑的输入框（兼容 React / Vue 等框架的受控输入）
- 右键选中网页文字 →「用 AI 翻译为英文」直接替换原文，提示条可一键撤销
- 右键选中 →「翻译为英文并复制」
- 快捷键 `Alt + Shift + T`：翻译选中的文字
- 术语表：固定专有名词译法；自定义系统提示词：完全接管翻译规则

## 安装

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本文件夹
3. 点击扩展图标 → ⚙ 设置 → 填入 DeepSeek API Key（[点此获取](https://platform.deepseek.com/api_keys)）→ 保存 → 可点「测试连接」

> Edge、Brave 等 Chromium 内核浏览器同样可用。

## 使用

| 场景 | 操作 |
| --- | --- |
| 先翻译再粘贴 | 点图标 → 输入中文 → `Ctrl + Enter` 或点「翻译」→ 「复制」/「填入网页输入框」 |
| 网页里已有中文 | 选中文字 → 右键「用 AI 翻译为英文」（或 `Alt+Shift+T`）→ 原文被替换为英文，提示条可撤销 |
| 只想拿到译文 | 选中文字 → 右键「翻译为英文并复制」 |

「填入网页输入框」依赖页面里最近聚焦过的输入框；若页面不支持（如 `chrome://` 页面），会自动改为复制到剪贴板。

## 设置项

| 项 | 说明 |
| --- | --- |
| API Key | 仅保存在本机 `chrome.storage.sync`，不会上传到第三方 |
| 模型 | `deepseek-chat`（推荐）/ `deepseek-reasoner` |
| 创造性 | temperature，翻译建议 0.1–0.4，默认 0.3 |
| 默认风格 | 弹窗中风格下拉框的默认值 |
| 术语表 | 每行 `中文 -> English`，保证术语一致 |
| 自定义提示词 | 留空使用内置翻译提示词；填写后将完全覆盖 |

## 文件结构

```
manifest.json    扩展清单（MV3）
background.js    DeepSeek 调用、右键菜单、快捷键
content.js       网页侧选区替换 / 插入输入框 / 提示条
popup.html|css|js      弹窗界面
options.html|css|js    设置页
icons/           图标
```

## 常见问题

- **提示"请求失败（HTTP 401）"**：API Key 错误或已失效。
- **提示"请求失败（HTTP 402）"**：DeepSeek 账户余额不足，请充值。
- **右键菜单没有出现**：确认已选中文字；部分页面（PDF 查看器、chrome:// 页面）不支持脚本注入。
- **快捷键无效**：在 `chrome://extensions/shortcuts` 中确认 `Alt+Shift+T` 未被占用，可自行修改。
