# 浏览器翻译插件（Chrome 扩展）

用 **DeepSeek** 一键**全文翻译**当前网页，也支持翻译选中的文字、填入输入框。

## 功能

- **全文翻译**：抓取页面可见正文 → 按语义分批发送给 DeepSeek → 直接在原位置替换为译文，保留原有排版、链接与样式
- **沉浸式双语对照**：译文统一以独立段落（虚线分隔）追加到原文所在段落的末尾，按钮、链接、表格单元格等一律同样处理，不会出现有的带分隔线、有的挤在原文行里
- **显示样式可配**：双语对照（默认）/ 只显示译文，在设置页统一配置，弹窗里也能随时切换
- **多种触发方式**：右键菜单、快捷键、扩展弹窗按钮；快捷键失效时还有页面级兜底监听
- **60+ 种语言**：中（简/繁）、粤、英、日、韩、法、德、西、葡、意、俄、阿拉伯、泰、越、印尼、马来、印地、孟加拉、土耳其、荷兰、波兰、希腊、希伯来、波斯……任意语种组合互译
- **源语言可选**：全文翻译支持指定源语言（默认自动检测），小众语言或中英夹杂的页面也能翻准
- 渐进式翻译：边翻边替换，全程不注入任何浮动面板，翻译过程不弹任何提示
- **跟随滚动翻译**：滚动停在哪儿就先翻哪儿——上下拖动时新进入视野的段落会被插到队首立即翻译，导航/页脚等次要区域自动靠后
- **动态内容不掉队**：无限滚动、懒加载、折叠展开后新出现的文字会自动补扫并入队列
- **漏译自动补救**：模型偶尔漏项时自动把该批拆成两半重试，仍未翻出的单条会带着退避重试 3 次，不会闷声丢段落
- 译文缓存（500 条 / 30 分钟）：重复内容不再二次计费
- 跳过代码块 / 跳过隐藏元素，技术文档不易被破坏
- 跳过无意义文本：纯数字、纯符号、以及孤立的单个字母（如列表标号 `A`）不会被翻译；`t-shirt`、`don't` 这类多字符词照常翻译
- **单条翻译**：弹窗中「源语言 → 目标语言」自由选择（源语言支持自动检测）
- 选中文字即时翻译并替换（目标语言跟随弹窗里的「单条翻译」，可撤销）

## 安装

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本文件夹
3. 点击扩展图标 → ⚙ 设置 → 填入 DeepSeek API Key（[点此获取](https://platform.deepseek.com/api_keys)）→ 保存
4. 建议顺手在设置页选择「目标语言」

> Edge、Brave 等 Chromium 内核浏览器同样可用。

## 使用方式

| 操作 | 说明 |
| --- | --- |
| 右键页面空白处 → **DeepSeek 全文翻译此页** | 最常用 |
| 快捷键 `Alt + Shift + T` | 全文翻译当前页（可在 `chrome://extensions/shortcuts` 修改） |
| 快捷键 `Alt + Shift + R` | 还原为原文 |
| 快捷键 `Alt + Shift + S` | 翻译选中的文字（替换为目标语言） |
| 扩展图标 → 选「源语言 → 目标语言」→「翻译此页」 | 不用快捷键也能用 |
| 选中文字 → 右键「用 AI 翻译为××」 | 局部翻译并可撤销，目标语言跟随弹窗的「单条翻译」 |

翻译全程不弹任何提示条（右上角干净，不会打断阅读）：

- 开始 / 进行中都不提示，译文直接出现在原文下方；想中断并还原随时按 `Alt+Shift+R`（或右键「恢复网页原文」）
- 只有异常才会提示：未配置 API Key、部分批次翻译失败、页面没有可翻译文字
- 译文边翻边出现，且跟随滚动：滚到哪一段，哪一段就优先被翻译
- **显示样式**：双语对照 / 只显示译文，在**设置页「基本设置 → 显示样式」**里统一配置，扩展弹窗里也能随时切换（已翻译的页面会立刻生效）

### 关于 Ctrl + T 与快捷键切换

Chrome / Edge 把 `Ctrl + T`（新建标签页）设为**浏览器保留快捷键**，`chrome.commands` 无法注册它，网页脚本也拦截不到。因此默认使用 `Alt + Shift + T`。

**快捷键无效或想换键位**：

1. 打开 `chrome://extensions/shortcuts`（设置页里也有入口链接），找到「浏览器翻译插件」
2. 点击对应动作右侧的编辑框，按下想要的组合键即可
3. 若编辑框显示灰色 / 提示冲突，说明该组合已被其他扩展或浏览器占用，换一个组合即可

扩展还内置了**页面级快捷键兜底**：即使 Chrome 的 commands 机制没触发（焦点在地址栏、快捷键被占用等），只要页面处于焦点状态，`Alt+Shift+T / S / R` 依然有效（由 background 统一节流，不会重复翻译）。

## 设置项

| 项 | 说明 |
| --- | --- |
| API Key | 仅保存在本机 `chrome.storage.sync`，只与 api.deepseek.com 通信 |
| 模型 | `deepseek-chat`（推荐，快）/ `deepseek-reasoner`（推理强，慢） |
| 全文翻译源语言 | 默认自动检测；指定后模型判断更稳（支持 60+ 语种） |
| 全文翻译目标语言 | 全文翻译的落地语言（支持 60+ 语种） |
| 显示样式 | 双语对照（沉浸式，默认）/ 只显示译文。**基本设置**里的全局项，右键、快捷键、弹窗触发的翻译都按它显示 |
| 每批字符数 | 默认 3000，单批最多 8 段。偏小批次更稳，偏大更省请求 |
| 并发请求数 | 默认 3（参考同类插件 2~3），最大 6。越大越快，但更容易触发限流 |
| 单次扫描段落上限 | 默认 3000；超出部分会在后续补扫中自动纳入，不会永久漏译 |
| 跳过代码块 | 默认开启，`code` / `pre` 不翻译 |
| 创造性 temperature | 翻译建议 0.1 ~ 0.4，默认 0.3 |
| 术语表 | 每行 `源 -> 目标`，保证术语一致 |
| 自定义提示词 | 填写后将覆盖内置的单条翻译提示词 |

> 弹窗里的「源语言 / 目标语言」是单条翻译专用的（默认 自动检测 → 英语），与全文翻译的语言相互独立；选中文字的右键翻译与快捷键翻译会跟随「单条翻译」的目标语言。

## 文件结构

```
manifest.json    扩展清单（MV3）
background.js    DeepSeek 调用（单条 / 批量）、右键菜单、快捷键
content.js       全文抓取、视口优先的动态翻译队列（滚动跟随 / 动态内容补翻）、DOM 替换；选中替换
content.css      沉浸式双语译文标记样式（无浮动面板）
langs.js         语言列表 60+ 语种（popup / options / background 共用）
popup.*          弹窗：翻译此页、显示样式、源/目标语言、单条翻译
options.*        设置页
icons/           图标
```

## 常见问题

- **HTTP 401**：API Key 错误或失效。
- **HTTP 402**：DeepSeek 账户余额不足。
- **HTTP 429**：请求过快，降低「并发请求数」或稍后重试（插件会自动重试两次）。
- **个别段落没翻**：模型漏项时插件会先把该批**拆成两半**分别重试（一直拆到单条），没翻出来的单条还会退避重试 3 次；仍不行就把「每批字符数」调到 1500 左右再试。
- **滚过去的部分没翻译**：插件会按滚动位置动态排队，并在队列见底时补扫全文档（隐藏后显示、懒渲染、超出单次扫描上限的内容都会被捡回来）。如果长期停在同一页，可以按一次 `Alt+Shift+T` 重新补翻。
- **某些页面没反应**：`chrome://` 页面、PDF 查看器、应用商店页不允许注入脚本。
- **块状变形**：翻译只改文本节点，不改动结构；若页面本身结构复杂可把「显示样式」切到「双语对照」确认对应关系。
